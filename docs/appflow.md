# App Flow
1. **Onboarding:** Input Income -> Tampil dashboard 50/30/20.
2. **Goal Setup:** Add Goal -> Form SMART & Inflasi -> Kalkulasi.
3. **Resolution (If fails):** Tampil popup rekomendasi -> User pilih penyesuaian (Waktu/Uang) -> Save.
4. **Dashboard:** Tampil progress bar per kategori (Needs/Wants/Goals).
5. **Tracking:** Modal Add Expense -> Pilih Kategori -> Update Dashboard.
