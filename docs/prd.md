# Product Requirements Document (PRD)
**Platform:** Web-based (Responsive). Local-first (LocalStorage/IndexedDB) untuk v1.
**Core Features:**
1. **SMART Goal Setter:** Input target, deadline, dan kalkulator inflasi otomatis.
2. **50/30/20 Budgeting:** Auto-split dari income; porsi 20% otomatis dialokasikan ke Goals.
3. **Goal Visualization & Resolver:** Cek apakah porsi 20% cukup untuk capai target. Jika tidak, beri 3 opsi (mundurkan deadline, kurangi target, tambah alokasi).
4. **Cashflow Tracker:** Input pengeluaran bulanan vs budget bulanan.
**Out of Scope:** Backend, Auth, Bank Integration.
