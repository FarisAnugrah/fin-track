# User Stories
1. **As a user**, I want to input my monthly income so that the app can split it into 50/30/20.
2. **As a user**, I want to set a goal with a timeline so that I know how much I need.
3. **As a user**, I want to see the inflation-adjusted cost of my goal so that I don't under-save.
4. **As a user**, I want to know if my goal is achievable with my 20% budget so I can adjust my expectations.
5. **As a user**, I want to log my daily expenses into Needs/Wants buckets so I can track my monthly cashflow.
